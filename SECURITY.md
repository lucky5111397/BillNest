# Security Policy

## Reporting Security Issues

We take the security of Brightloop Subscription Management System seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report vulnerabilities using GitHub's **Private Vulnerability Reporting**:

1. Navigate to the repository's main page on GitHub.
2. Click on the **Security** tab.
3. Click on **Advisories** under "Vulnerability alerts".
4. Click **Report a vulnerability** to submit your report confidentially to repository maintainers.

### What to Include

When reporting a vulnerability, please provide:

- A descriptive summary of the potential vulnerability.
- Clear reproduction steps or a minimal proof of concept.
- The affected component (e.g., API authentication, database query, frontend dependency).
- Any potential mitigation steps or recommendations if known.

Maintainers will review the report, validate findings, and coordinate a patch through a private security advisory before public disclosure.
